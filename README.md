## 📦 What is a Variable?

Think of a variable as a **labeled storage box** in memory:
1. **Type:** What shape is the box? (`int`, `float`, `char`)
2. **Name (Identifier):** What label is on the outside? (`number`, `pi`, `letter`)
3. **Value:** What item is placed inside? (`5`, `3.14`, `'A'`)

data_type variable_name = value;
